# 2026-10-13 运营优化诊断（本周计划建议）

结论：先查并小范围试验配置推荐；先核对 Banner 是否正常投放；保留当前改善的算法推荐、安卓活跃和 PC 活跃策略，不做全局回退或扩大提权。完整口径下配置点击/页面曝光下降 1.31pp，并非新增分母直接污染造成；剔除异常日后下降方向仍成立。城市优化优先级应从泛化的“江苏、浙江、山东”进一步收窄到可复核的城市与配置问题。

## 2. 四类入口：配置优先，算法和广告不宜一起调整

以下均采用相同星期 5 天。

| 入口 | 分子/分母：前→后 | 率变化 | 可得结论 |
|---|---|---|---|
| 配置推荐 | 348/1,599 → 266/1,364 | 21.76%→19.50%，−2.26pp | 点击减少82，下降方向三种口径一致，优先核查 |
| 算法推荐 | 179/1,506 → 161/1,279（算法曝光） | 11.89%→12.59%，+0.70pp | 点击人数随曝光减少，曝光后点击率改善，不应整体回退 |
| 本地包 Banner | 21/1,599 → 9/1,364 | 1.31%→0.66%，−0.65pp | 先查展示、排期与素材是否相同；没有 Banner 自身曝光，不能判定素材 CTR 下跌 |
| 广告位 | 84/1,599 → 69/1,364 | 5.25%→5.06%，−0.19pp | 比例变化小，暂不据此整体换游戏；没有独立广告曝光 |

算法曝光覆盖页面的比例为94.18%→93.77%（−0.42pp），并未出现大幅覆盖变化。四类用户可以重叠，不能将四类点击率相加、不能把某一入口的变化解释成总启动的确定贡献。

同时，新用户总启动 1,758/2,604=67.51%→1,583/2,291=69.10%（+1.58pp）；游戏模块开始玩 468/2,604=17.97%→473/2,291=20.65%（+2.67pp），搜索点击15.78%→14.58%（−1.20pp）。这些是并行信号，不能相加归因；优先保留改善的游戏模块，搜索留作后续查询词与结果覆盖巡检。平台活动 Banner 的10→0点击与本地包 Banner 的21→9是不同事件，不混用。

## 3. 曝光量、地域结构与同城率变化

同星期口径：页面曝光1,599→1,364（−14.70%），配置点击348→266（−23.56%）。用对称分解，少82个点击可描述为曝光量变化约−48.49、总体点击率变化约−33.51。只是算术拆分，不是可恢复用户预测。

以页面曝光份额为权重，配置率−2.26pp分解为：

- 省级：同省率变化−2.47pp，省份曝光结构变化+0.20pp。省份结构整体稍有缓冲，并非主要拖累。
- 城市级：两期都有曝光的同城率变化−2.64pp，城市曝光结构+0.97pp，仅一期有曝光的城市净贡献−0.59pp。小城市自然进出、地域归属也会影响后一项，不解释为真实城市流失。

方法：同省/同城率贡献为平均曝光份额乘以率变化；结构贡献为平均率乘以份额变化。两期之一曝光为零的地区单列，不将缺失率补零后混入同城变化。

| 优先核查城市 | 配置点击/页面曝光 前→后 | 净点击变化 | 全国配置率变化的算术贡献 |
|---|---|---:|---:|
| 上海 | 11/37=29.73% → 3/27=11.11% | −8 | −0.47pp |
| 成都 | 10/30=33.33% → 5/30=16.67% | −5 | −0.26pp |
| 苏州 | 6/28=21.43% → 1/19=5.26% | −5 | −0.30pp |

三地在完整7天、仅去本周异常日、同星期5天三种口径下都走弱；同星期共少18次日UV点击，占全量净少82的约22%，全国率的净贡献合计−1.03pp。这里的“贡献”含份额和同城率，不能当作因果贡献或优化收益。三地各仅19–37个页面曝光，优先巡检而非直接判定游戏无效。

其它值得区分的地区：

- 浙江省页面曝光154→154、配置点击30→23，需查配置；但杭州5/35→4/49、台州6/30→5/26对全国率的净贡献分别仅−0.02pp、−0.01pp，不应继续简单指定它们为主要拖累。嘉兴4/11→0/11、济南10/16→6/17样本过小，列二级复核。
- 上饶6/7→0/9在排序中很突出，但极小样本，应先查记录与配置，不因85.7%→0%就给全省下结论。
- 无锡6/15→3/8、赤峰8/28→5/15，主要是曝光量变少；赤峰率28.57%→33.33%还上升，不宜因为点击人数少就换游戏。
- “云南/云南”等省级地区行不是已定位的真实城市，不能直接生成城市执行任务。

## 4. 前三个可控动作与最小试验

### 动作一：先核查上海、成都、苏州配置，再做一项小范围试验

今天可做：逐一核对线上配置版本、生效时间、游戏是否可用、配置是否命中、现有排序与运营配置表是否一致。异常问题先修复；没有发现配置差异时，保持现状采集分游戏数据，不凭省均值盲换游戏。浙江省做同样的配置巡检，嘉兴、济南等小样本城市先观察。

最小试验：定位到具体可控项后，只改一个配置游戏或一项排序规则，不同时改 Banner、算法和广告位；同城市、同版本、人群内稳定随机分组，对照保留当前配置。随机能力不可用时，采用同城星期匹配的分时交叉观察，并明确其因果证据更弱。至少跑完整7天，建议跨两个完整周；根据事先确定的最小有意义提升计算样本，不够量不判赢、不扩量。三个城市当前流量很小，不能把7–14天当作保证足够样本。

主指标：配置推荐点击UV/页面曝光UV；若补到独立配置曝光，再辅看配置CTR。护栏：安卓新用户总启动率、本地包总点击/页面曝光，以及启动失败或投诉；不能为了配置点击而损害总启动。全国有效5天率19.50%不是三城试验对照率，试验使用同城并行对照。

### 动作二：本地包 Banner 先做投放与可见性巡检，再决定素材试验

依据：点击21→9、点击/页面曝光1.31%→0.66%；但只有12个点击差额，没有自身曝光数据。先核对10/7、10/8、10/10–10/12与对应星期的排期、配置命中、素材加载及跳转是否一致。若确有停投、未展示或加载问题，先修这些问题；不能直接判定“素材变差”。

最小试验：确认相同展示条件后，仅替换一个素材或文案版本，稳定分组、固定展示资格和位置，保留原素材为对照；不与配置推荐试验在同一批用户同时叠加。主指标为Banner点击UV/独立Banner曝光UV；没有该曝光时，只能继续观察页面口径，不能宣称素材CTR提升。护栏为总启动率、页面加载失败和跳转成功率。小样本下先排障、再试验，广告位目前5.25%→5.06%，暂保持。

### 动作三：保留改善的活跃策略，先验证来源再放量

完整7天正式口径（不排除新用户异常日期）：

- 安卓活跃：533,666/1,220,557=43.72% → 537,885/1,225,364=43.90%，+0.17pp；进入人日+0.79%，用户池+0.39%。
- PC活跃：146,861/570,043=25.76% → 184,128/663,679=27.74%，+1.98pp；进入人日+25.38%，用户池+16.43%。营收棋牌率贡献+1.90pp，只创角联运且未进入棋牌的占比+0.08pp。后者是并集的算术拆分，不能把棋牌与联运原始率相加。

只作日期稳健性检查时，相同星期5天安卓43.68%→44.02%、PC25.53%→28.41%，改善方向未反转；这不是发现活跃模块存在异常，也不更改其正式7天数据。

今天可做：维持安卓第2日起活跃分发策略、PC现有权重，冻结一份当前配置作为对照，不因总体上涨就继续全量加权。最小后续试验是在同地区、同活跃层或用户年龄层保留稳定对照，只测试一个待验证的权重差异。主指标为进入营收游戏去重并集UV/活跃用户池UV；护栏为次日/7日活跃、启动失败、可获取的收入或付费指标。安卓优先补第2–3日与第4日及以后分层；PC补高活跃地区和游戏拆分。当前只有平台总量，不能认定PC改善是现有提权造成。
